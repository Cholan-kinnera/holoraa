# Security Policy

Holoraa takes the security and privacy of its users and their data seriously. Thank you for reporting problems responsibly.

## Supported versions

Holoraa has no release yet. Only the current development branch is maintained. A supported-version table will be added at the first release.

## Reporting a vulnerability

**Do not report vulnerabilities in public issues or pull requests.**

1. Use GitHub's private vulnerability reporting, from the repository's Security tab, if it is enabled. `TODO(owner): confirm it is enabled.`
2. Or email `TODO(owner): dedicated security contact address`.

Please include:
- the type of issue (for example, injection, cross-site scripting, token leakage, server-side request forgery, or authorisation bypass),
- steps to reproduce, with a minimal proof of concept if you have one,
- the impact you expect,
- any fix you suggest.

Do not include real personal data, real credentials, or anyone else's data in a report. If you find a credential, report its location and do not use it.

## Response targets (proposed)

These are targets, not commitments, until the owner confirms them:
- acknowledgement within 48 hours,
- triage and severity assessment within 5 business days,
- a fix or mitigation within 30 days, depending on severity,
- coordinated disclosure after the fix is verified.
